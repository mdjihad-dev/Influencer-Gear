# Influencer Gear

A responsive product-focused landing page for an influencer equipment store. The project combines product cards, navigation, brand sections, and responsive layouts into a single frontend experience.

## Tech Stack

- HTML5
- CSS3
- Responsive Web Design
- Font Awesome

## Highlights

- Product-focused hero section
- Product collection cards
- Brand showcase section
- Navigation and shopping UI
- Responsive layout

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/Influencer-Gear.git
cd Influencer-Gear
```

## Project Focus

The project was built to practice responsive e-commerce-style interfaces, card layouts, navigation, visual hierarchy, and frontend styling with HTML and CSS.
